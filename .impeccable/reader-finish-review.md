# Independent evidence-reader finish review

Disposition: ship

## persistence

This is a narrow extension of the approved workbench B and catalogue direction. It keeps the photographic inspection surface, original evidence, editorial fonts, warm paper and fine rules. The React/local Python and labelled public-preview split remain intact. Source reading is an in-site task with a return link and original download, rather than an unrelated document interface. The existing first-body-child contract and prior design decisions persist.

## fidelity

Saved reader-8765-desktop.png and reader-8766-desktop.png show the same legible Markdown layout in local and public modes. Original document headings and prose remain recognizably source material below the project title, file path, download and optional SHA-256 identity. Reader mobile JSON crops retain readable keys, values, wrapping hashes and nested details without page-width overflow. Structured records are long because the complete original record is long; expandable groups let readers reduce that detail. Tables use a keyboard-focusable, horizontally scrollable region rather than shrinking text or overflowing the page. Mobile humanized-methods captures show clear method headings, body copy and rationale at usable size.

EvidenceReader fetches an indexed original path, parses Markdown with GFM and skipHtml, renders CSV/lock tables and structured JSON, and provides the original file download. Local relative links resolve against the document's directory and stay in the reader when indexed. Images use indexed originals. Loading, abort-on-navigation, source-unavailable and retry states are present. This review found no source Markdown fragment links that would require generated heading anchors.

Authenticity was checked against the actual preserved_at mapping in historical_preservation.json: all 232 indexed originals exist and match their declared SHA-256. The apparent root README mismatch is intentional; the reader serves the preserved original README, while the current navigation README is separate. Local server and public build both use this mapping, and the public build verifies source hashes before copying. The reader describes a stored identity without claiming an additional runtime verification.

The prose revision gives actions and explanations clearer subjects while retaining the important factual boundaries: frozen pretrained features, normal-only reference fitting/calibration, strict thresholds, exact 180-degree correction, uncertain no-op, exposed development phases, known misses, uncalibrated maps and proposed future studies. Athena remains workflow inspiration with an independent-project boundary. The parent corrected the Model section heading to Model limitations; observed failures are no longer described as merely untested conditions. The purpose now explicitly describes a reference built from normal images rather than training the frozen feature network on those boards.

## ceiling

The source reader meets the incumbent craft level without redesigning the inspection product. It addresses the user's four raw methods links with readable source views, retains original evidence and does not rewrite historical scientific documents to sound friendlier. Current source and supplied local/public desktop/mobile captures support shipping. No detector rerun was needed or performed by this reviewer.
